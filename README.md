# Laravel на Amvera

Простой пример деплоя Laravel в [Amvera](https://amvera.ru).

Это тестовое приложение показывает работу API routes, controller, валидации, статических файлов и персистентное сохранение JSON в постоянное хранилище Amvera.

## Демо-приложение

Приложение имеет веб-интерфейс, на котором вы сразу можете выполнить доступные тестовые запросы.

- `GET /api/health`
- `GET /api/items`
- `POST /api/items`
- `DELETE /api/items/{id}`

## Как правильно сохранять файлы

Любые изменяемые файлы необходимо сохранять в [постоянное хранилище Amvera](https://docs.amvera.ru/applications/storage.html#data). Файлы внутри директории с кодом могут быть потеряны после пересборки приложения.

## Статические файлы

Публичные файлы Laravel находятся в `public`. Веб-корнем приложения должна быть именно эта директория.

Ссылки на статику строятся от корня сайта:

```html
<link rel="stylesheet" href="/styles.css">
```

## APP_KEY

Конкретно это приложение работает без `APP_KEY`. Однако, если вы добавите сессии, cookies или шифрование, вам нужно будет добавить переменную-секрет `APP_KEY`. Сгенерировать значение можно локально с помощью команды `php artisan key:generate --show`.

Директории `storage` и `bootstrap/cache` должны оставаться доступными для записи (если их не загрузить, сборка упадет с ошибкой).

## Локальный запуск

```bash
composer install
php artisan serve --host=0.0.0.0 --port=5000
```

Откройте localhost:5000.

## Деплой в Amvera

Для деплоя конкретно этого приложения вам понадобится:

1. Создать аккаунт в [Amvera](https://cloud.amvera.ru);
2. Создать обычное приложение в любом регионе;
3. Загрузить в него код репозитория;
4. При необходимости задать "APP_KEY" во вкладке "Переменные";
5. Во вкладке "Конфигурация" нажать кнопку "Собрать".

Когда приложение будет готово к работе и статус сменится на "Запущено", во вкладке "Домены" можно будет создать бесплатное доменное имя от Амвера.
